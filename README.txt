TSHP — Seishou Koyama Story Website

This folder is a static, hosting-ready website. It no longer depends on a computer-specific
file:/// path. Keep index.html, koyama.jpg, and tshp-logo.png in the same folder when uploading it.

To make it publicly accessible:
1. Upload these files to a static hosting service (for example GitHub Pages, Netlify, or Cloudflare Pages).
2. Set index.html as the site entry point.
3. Share the public https:// address generated by the host.

Do NOT share a file:///media/... address: that points to a file on one computer only.
